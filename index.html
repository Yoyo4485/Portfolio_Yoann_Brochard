Présentation

Actuellement étudiant en BTS Services Informatiques aux Organisations (SIO), spécialité SISR (Solutions d’Infrastructure, Systèmes et Réseaux), je me forme aux différents domaines liés à l’administration des systèmes et des réseaux informatiques. Cette formation me permet de développer des compétences techniques en configuration de serveurs, gestion des équipements réseau, virtualisation, cybersécurité ainsi qu’en administration des environnements Linux et Windows.

Au cours de ma formation, j’ai également appris à utiliser plusieurs outils et technologies liés au monde professionnel, notamment dans la gestion des utilisateurs, des services réseau ou encore le déploiement et la maintenance d’infrastructures informatiques. Curieux et motivé, j’apprécie particulièrement la résolution de problèmes techniques ainsi que la découverte de nouvelles technologies.

À travers ce portfolio, je souhaite présenter mon parcours, les compétences que j’ai acquises, ainsi que les différents projets et expériences réalisés durant mon BTS. Mon objectif professionnel est de poursuivre dans le domaine des systèmes et réseaux afin d’évoluer vers un métier lié à l’administration ou à la gestion d’infrastructures informatiques.

Projet Python

Contexte :
La société fictive STESIO souhaite se conformer aux obligations légales relatives à l'utilisation d'Internet sur le lieu de travail. Pour ce faire, elle a mis en place un proxy permettant de journaliser tous les accès web effectués par ses salariés. Le fichier de log généré (log_proxy.txt) contient des informations telles que l’adresse IP, la date, l’heure, la commande HTTP (GET ou POST), ainsi que les URL des éléments consultés (pages, images, etc.). À partir de ces journaux volumineux, le responsable du système d'information souhaite produire des statistiques telles que : Les sites les plus consultés, La liste des utilisateurs les plus consommateurs, Et dans des cas spécifiques (ex. : enquête de police), pouvoir répondre à des requêtes précises du type : "Qui a consulté tel site, à telle date et telle heure ?" Pour répondre à ces besoins, une base de données Oracle a été conçue avec les tables suivantes : SALARIES(num, nom, prenom, adresseIP) PROXY(id, adresseIP, jourheure, URL) En parallèle, STESIO souhaite également automatiser la création des comptes utilisateurs du SGBD à partir d’un annuaire Windows. Un script Python est utilisé pour lire un fichier texte contenant la liste des utilisateurs, puis générer automatiquement les commandes SQL de création de comptes.

Objectifs du projet :
L’entreprise fictive STESIO souhaitait mettre en place une solution permettant d’exploiter et d’analyser des fichiers logs issus d’un serveur proxy. L’objectif du projet était de développer plusieurs outils en Python et SQL capables de :

  • Extraire et analyser les informations contenues dans les fichiers logs
  • Générer automatiquement des fichiers CSV et des scripts SQL
  • Importer les données dans une base de données MariaDB
  • Produire des statistiques sur les connexions et les URL les plus consultées
  • Automatiser le traitement et l’archivage des journaux
  • Réaliser des analyses et visualisations des données collectées

Étapes du projet :
Le projet a été réalisé en plusieurs phases afin de permettre l’analyse et l’exploitation des fichiers logs :

  • Analyse du cahier des charges et étude de la structure des fichiers logs
  • Création de scripts Python pour lire, traiter et analyser les données
  • Génération automatisée de fichiers CSV et de scripts SQL
  • Mise en place et configuration d’une base de données MariaDB
  • Importation et exploitation des données dans la base de données
  • Création de requêtes SQL pour produire des statistiques et rechercher des informations précises
  • Développement d’outils d’automatisation pour le traitement des logs
  • Réalisation de visualisations et analyses graphiques des données
  • Mise en place de solutions d’archivage et de sécurisation des journaux

Projet GSB

Contexte :
Dans le cadre de la première année de BTS SIO SISR, un Projet Personnalisé Encadré (PPE) a été réalisé sur une période de 4 semaines, en avril 2017, par groupe de trois étudiants. Le projet porte sur les besoins du laboratoire pharmaceutique fictif Galaxy Swiss Bourdin (GSB), qui souhaite centraliser la gestion des comptes-rendus de visite ainsi que les frais professionnels engagés par ses visiteurs médicaux. Pour cela, le laboratoire a décidé de développer en interne une application web sécurisée, intitulée GSB-AppliFrais, hébergée sur sa propre infrastructure réseau. Cette application permettra à l’ensemble de la force commerciale (visiteurs médicaux) de saisir les comptes-rendus et frais liés à leurs déplacements (hébergement, restauration, transport…), mais également aux équipes comptables de valider et mettre en paiement ces frais via un module d’administration sécurisé.

Objectifs du projet:
L’objectif du projet était de mettre en place une infrastructure complète permettant le fonctionnement de l’application GSB, en répondant à plusieurs besoins techniques :

  • Concevoir une architecture réseau séparant les environnements DMZ et PROD
  • Mettre en place un serveur web sécurisé accessible en HTTPS
  • Installer et configurer un serveur de base de données dédié
  • Configurer un serveur DNS pour la résolution des noms internes
  • Mettre en place un serveur FTP pour les mises à jour de l’application
  • Assurer la communication sécurisée entre les différents services
  • Appliquer des règles de sécurité et de restriction d’accès selon les rôles utilisateurs
Mais aussi l'objectif était de nous mettre en groupe de 4 afin de se rapprocher d’un fonctionnement professionnel. Le travail était réparti entre les différents membres de l’équipe avec des échanges réguliers pour suivre l’avancement du projet, partager les solutions trouvées et coordonner les différentes tâches à réaliser. Cette organisation nous a permis de développer le travail collaboratif ainsi qu’une approche proche des méthodes utilisées en entreprise.

Architecture du projet :
Afin de répondre aux besoins de l’application, l’infrastructure mise en place comprenait plusieurs machines virtuelles ayant chacune un rôle précis :

  • Un serveur Web Apache pour héberger l’application
  • Un serveur de base de données MySQL/MariaDB
  • Un serveur DNS pour la résolution des noms de domaine
  • Un serveur FTP permettant les transferts de fichiers internes
  • Des équipements réseau assurant la communication et la segmentation des réseaux
  • Une machine cliente permettant de tester les différents services déployés
L’ensemble de l’infrastructure a été virtualisé afin de faciliter les tests, le déploiement et l’administration des différents services.

Étapes du projet :
Le projet a été réalisé en plusieurs phases :

  • Analyse du cahier des charges et définition des besoins
  • Mise en place et configuration des machines virtuelles
  • Configuration du réseau, du routage et du service DNS
  • Installation et sécurisation du serveur web et de la base de données
  • Mise en place du protocole HTTPS et des accès sécurisés
  • Configuration du serveur FTP pour les échanges internes
  • Réalisation des tests de fonctionnement et de sécurité
  • Documentation de l’infrastructure et des différentes configurations réalisées

Projet Docker

Contexte :
Dans ce projet réalisé en groupe de trois, nous avons conçu une infrastructure à haute disponibilité en utilisant Docker. L’objectif était de répartir la charge entre plusieurs serveurs web via un répartiteur de charge, puis d’y ajouter une couche de gestion de base de données avec MariaDB. Chaque composant de l’architecture (serveurs web, base de données, répartiteur) a été déployé dans un conteneur Docker indépendant. Une page PHP permettait d’afficher dynamiquement le nom de chaque serveur à l’aide de la fonction gethostname() pour vérifier la répartition. La base de données MariaDB contenait une table personne, consultable via une autre page PHP connectée à cette base. Toute l’infrastructure a été documentée et testée, notamment en cas de panne d’un des serveurs web.

Missions :
Installation Docker, configuration HAProxy, MariaDB, réseau personnalisé, pages PHP dynamiques, documentation complète.

Objectif du projet :
Le projet Docker avait pour objectif de mettre en place une infrastructure virtualisée capable d’héberger une application de gestion des ressources humaines reposant sur une base de données distante.

Le projet devait permettre de découvrir le fonctionnement de Docker ainsi que le déploiement de services dans des conteneurs afin de faciliter l’installation, la communication entre services et l’administration de l’infrastructure.

Étapes du projet :
Le projet a été réalisé en plusieurs étapes :

  • Constitution des équipes et organisation du travail
  • Découverte de l’environnement Docker et des conteneurs
  • Mise en place de Portainer pour l’administration Docker
  • Création et configuration de conteneurs Apache
  • Mise en communication des services Apache et MariaDB
  • Déploiement automatisé avec Docker Compose
  • Création d’images Docker personnalisées
  • Réalisation de tests de fonctionnement et documentation du projet

Projet Croisère

Contexte :
Dans le cadre du projet MSC Croisières, nous intervenons sur la mise en place du système informatique d’un navire, plus précisément sur le pont n°7. L’objectif est de concevoir un réseau structuré, sécurisé et fonctionnel permettant de répondre aux besoins des utilisateurs à bord. Le système doit permettre de gérer différents types d’utilisateurs, notamment le personnel et les passagers, à travers des réseaux distincts. Il doit également assurer l’accès aux services informatiques, à Internet, ainsi que la communication entre les équipements. Des exigences importantes sont présentes, notamment en matière de sécurité, de gestion des accès, de supervision du réseau et de gestion du parc informatique. L’infrastructure doit aussi garantir la disponibilité des services et la protection des données. Enfin, le projet s’inscrit dans une logique professionnelle avec une organisation en plusieurs phases, incluant l’analyse des besoins, la mise en place des solutions techniques et la validation de leur bon fonctionnement.

Objectif du projet :
L’objectif du projet MSC Croisières était de concevoir et mettre en place une infrastructure réseau complète et sécurisée destinée au pont n°7 d’un paquebot. Le projet devait permettre de répondre aux besoins du personnel et des passagers à travers la mise en place de plusieurs services réseaux et systèmes : segmentation des réseaux en VLAN, gestion du Wifi, routage, NAT, Active Directory, supervision, cybersécurité et automatisation.

Étapes du projet :

  • Sprint 1 : Organisation du projet et analyse du cahier des charges Analyse des besoins, répartition des tâches, mise en place de Trello et du stockage partagé, préparation des documents techniques et organisation du travail d’équipe.
  • Sprint 2 : Maquette de l’infrastructure avec Packet Tracer Conception de la maquette réseau virtuelle avec les VLAN, le Wifi, le DHCP et les tests de communication réseau.
  • Sprint 3 : Mise en place du routeur et du switch Configuration des équipements réseau physiques, du routage, du NAT, des VLAN ainsi que réalisation du schéma physique de l’infrastructure.
  • Sprint 4 : Mise en place de l’Active Directory Déploiement du serveur Active Directory, création des utilisateurs, groupes, partages réseau et intégration des postes au domaine.
  • Sprint 5 : ACL et réseau Wifi Configuration des ACL de sécurité, mise en place des réseaux Wifi et séparation des accès entre les différents utilisateurs.
  • Sprint 6 : Mise en place de GLPI Installation et configuration de GLPI pour la gestion de parc informatique, l’inventaire et la gestion des tickets.
  • Sprint 7 : Authentification Radius Mise en place d’un serveur Radius afin de sécuriser l’authentification Wifi des utilisateurs.
  • Sprint 8 : Intégration d’une station Linux dans le domaine Configuration et intégration d’une machine Linux dans l’environnement Active Directory.
  • Sprint 9 : Scripts PowerShell Création de scripts PowerShell permettant d’automatiser certaines tâches d’administration et de gestion des partages.
  • Sprint 10 : Mise en place de Stormshield Déploiement et configuration du firewall Stormshield afin de renforcer la sécurité réseau.
  • Sprint 11 : VPN SSL et sécurité réseau Configuration du VPN SSL et amélioration de la sécurisation des communications réseau.
  • Sprint 12 : Supervision avec Nagios Mise en place de Nagios afin de superviser les équipements et services de l’infrastructure.
  • Sprint 13 : SIEM Wazuh Déploiement de Wazuh pour la surveillance de sécurité et l’analyse des événements système et réseau.
  • Sprint 14 : Déploiement automatisé avec Ansible Mise en place d’Ansible afin d’automatiser le déploiement de logiciels et certaines tâches d’administration.

Veille Technologique

Question

Quels sont les avantages et les défis de la migration vers les réseaux 6G dans les entreprises d'ici 2030 ?

Présentation de la 6G

La 6G représente la future génération des réseaux mobiles qui succédera à la 5G à l’horizon 2030. Son objectif principal est de proposer des vitesses beaucoup plus élevées, une latence extrêmement faible ainsi qu’une connectivité intelligente capable d’intégrer l’intelligence artificielle directement dans les réseaux.

La 6G devrait permettre de connecter en temps réel des milliards d’appareils, de véhicules, de capteurs et de systèmes automatisés. Cette technologie ne servira pas uniquement à améliorer Internet sur smartphone, mais également à développer des domaines comme les villes intelligentes, la médecine à distance, l’industrie automatisée, les véhicules autonomes ou encore les communications immersives en réalité virtuelle et augmentée.

Les avantages de la 6G

La 6G devrait permettre des vitesses de connexion extrêmement élevées, bien supérieures à celles de la 5G actuelle. Les entreprises pourront transférer et traiter d’énormes quantités de données quasiment instantanément. Cela sera particulièrement utile pour les infrastructures cloud, les centres de données, les applications professionnelles en temps réel ou encore les plateformes collaboratives utilisées à distance. Les secteurs industriels pourront également exploiter davantage l’automatisation grâce à des échanges de données beaucoup plus rapides et plus stables.

Source

La réduction très importante de la latence représente aussi un avantage majeur. Avec la 6G, le délai de transmission des informations pourrait devenir presque instantané. Cela ouvrirait la voie à des technologies avancées comme les véhicules autonomes, la chirurgie à distance, la robotique industrielle ou les systèmes de sécurité intelligents. Dans une entreprise, cette rapidité permettra une meilleure réactivité des systèmes informatiques et une communication plus fluide entre les machines, les serveurs et les utilisateurs.

Source

La 6G devrait également intégrer l’intelligence artificielle directement au sein du réseau. Les infrastructures seront capables d’analyser automatiquement les besoins des utilisateurs afin d’optimiser les performances et la gestion du trafic. Par exemple, un réseau pourra adapter automatiquement la bande passante disponible selon les usages prioritaires d’une entreprise. Cette automatisation permettra d’améliorer la stabilité des réseaux et de limiter certaines interventions humaines dans l’administration des infrastructures.

Source

Le développement massif des objets connectés sera aussi facilité par la 6G. Les entreprises pourront connecter un nombre très important d’équipements simultanément sans perte de performance. Cela permettra le développement des usines intelligentes, des bâtiments connectés, des systèmes de surveillance avancés ou encore des villes intelligentes. Dans l’industrie, les capteurs pourront communiquer en permanence afin d’améliorer la maintenance prédictive, la sécurité et l’automatisation des chaînes de production.

Source

Les défis et inconvénients de la 6G

Même si la 6G apporte de nombreuses innovations, son déploiement représentera un coût très important pour les entreprises et les opérateurs télécoms. La mise en place de cette technologie nécessitera de nouvelles infrastructures réseau, de nouveaux équipements ainsi qu’un grand nombre d’antennes supplémentaires. Certaines entreprises devront également renouveler une partie de leur matériel informatique afin de rester compatibles avec ces nouvelles technologies. Ces investissements pourraient ralentir l’adoption de la 6G, notamment pour les petites structures.

Source

La cybersécurité représente également un défi majeur. Avec des milliards d’appareils connectés et une utilisation massive de l’intelligence artificielle, les risques de cyberattaques pourraient fortement augmenter. Les réseaux 6G transporteront des quantités très importantes de données sensibles, ce qui attirera davantage les cybercriminels. Les entreprises devront donc renforcer leurs systèmes de sécurité afin de protéger leurs infrastructures, leurs données et leurs utilisateurs contre les intrusions ou les vols d’informations.

Source

Des difficultés techniques importantes existent également. La 6G utilisera des fréquences beaucoup plus élevées que les générations précédentes. Ces fréquences permettent des débits très rapides mais elles ont une portée plus faible et traversent moins bien les obstacles comme les murs ou les bâtiments. Pour garantir une couverture correcte, il faudra installer davantage d’équipements réseau et développer de nouvelles solutions techniques capables d’assurer une connexion stable.

Source

La consommation énergétique pourrait aussi devenir un problème important. Les infrastructures 6G demanderont une puissance de calcul très élevée afin de gérer l’intelligence artificielle, les objets connectés et les énormes flux de données. Même si certains travaux cherchent à améliorer l’efficacité énergétique des futurs réseaux, la consommation électrique des centres de données et des équipements télécoms pourrait fortement augmenter. Cela soulève des questions environnementales importantes pour les entreprises et les gouvernements.

Source

Enfin, la 6G soulève également des questions liées à la confidentialité et à la protection de la vie privée. Les futurs réseaux seront capables de collecter et d’analyser énormément d’informations en temps réel grâce aux objets connectés et à l’intelligence artificielle. Certaines technologies pourraient même permettre de localiser ou d’analyser très précisément les comportements des utilisateurs. Les entreprises devront donc respecter des règles strictes concernant la protection des données personnelles et la gestion des informations sensibles.

Source

État actuel de la technologie 6G

Actuellement, la 6G est encore en phase de recherche et de développement. Les réseaux 6G ne sont pas encore disponibles commercialement, mais de nombreux acteurs comme Ericsson, Qualcomm, Nokia ou encore plusieurs universités et organismes internationaux travaillent déjà sur les futures normes et infrastructures. Les recherches portent principalement sur l’intégration de l’intelligence artificielle dans les réseaux, les communications ultra-rapides, les objets connectés massifs et les technologies utilisant des fréquences très élevées. Des prototypes et des démonstrations techniques ont déjà été présentés lors d’événements internationaux comme le Mobile World Congress 2026.

Source

Les organismes de standardisation comme l’ITU et la 3GPP ont commencé à définir les premières spécifications techniques de la 6G, appelées IMT-2030. Les premières véritables normes devraient arriver entre 2027 et 2029, avec un début de commercialisation prévu autour de 2030. Aujourd’hui, les travaux se concentrent surtout sur les tests, les prototypes et les expérimentations afin de préparer les futures infrastructures réseau.

Question

Quels sont les avantages et les risques du cloud computing pour les entreprises ?

Présentation du Cloud Computing

Le cloud computing, aussi appelé « informatique en nuage », est une technologie permettant de stocker, gérer et utiliser des données ou des services informatiques à distance via Internet. Au lieu d’installer des serveurs et logiciels directement dans les locaux d’une entreprise, les ressources sont hébergées dans des centres de données appartenant à des fournisseurs spécialisés comme Amazon Web Services, Microsoft ou Google.

Le cloud permet aux entreprises d’accéder à leurs fichiers, applications ou infrastructures depuis n’importe quel appareil connecté à Internet. Cette technologie est aujourd’hui très utilisée pour l’hébergement de sites web, les sauvegardes de données, les serveurs virtuels, les outils collaboratifs ou encore l’intelligence artificielle. Le cloud computing est devenu un élément essentiel dans la transformation numérique des entreprises.

Source

Les avantages du cloud computing

Le cloud computing permet tout d’abord une grande flexibilité pour les entreprises. Les ressources informatiques peuvent être augmentées ou réduites rapidement selon les besoins. Une entreprise peut par exemple ajouter de nouveaux serveurs, augmenter son espace de stockage ou déployer une nouvelle application en quelques minutes seulement. Cela facilite énormément l’évolution des infrastructures sans devoir acheter immédiatement du nouveau matériel physique. Cette flexibilité est particulièrement utile pour les entreprises connaissant des périodes de forte activité ou une croissance rapide.

Source

Le cloud permet également de réduire les coûts informatiques. Les entreprises n’ont plus besoin d’acheter et de maintenir autant de serveurs physiques dans leurs locaux. Les fournisseurs cloud prennent en charge une grande partie de la maintenance, des mises à jour et de la gestion matérielle. Les entreprises paient généralement uniquement les ressources qu’elles utilisent, ce qui limite certains investissements importants en infrastructure. Cela représente un avantage important pour les petites et moyennes entreprises qui ne disposent pas forcément de grands moyens techniques ou financiers.

Source

Le cloud améliore aussi l’accessibilité et le travail collaboratif. Les employés peuvent accéder aux données et aux applications depuis différents lieux grâce à Internet. Cela facilite fortement le télétravail et le partage de documents entre équipes. Les outils collaboratifs hébergés dans le cloud, comme les suites bureautiques en ligne ou les plateformes de stockage partagé, permettent une meilleure communication et une plus grande productivité dans les entreprises.

Source

La sécurité et les sauvegardes automatiques représentent également un avantage important. Les grands fournisseurs cloud disposent de centres de données hautement sécurisés avec des systèmes de sauvegarde, de redondance et de surveillance avancés. En cas de panne matérielle ou de problème technique, les données peuvent être restaurées plus facilement. Certaines solutions cloud proposent également des protections avancées contre les cyberattaques et les pertes de données.

Source

Enfin, le cloud facilite le déploiement rapide de nouvelles technologies comme l’intelligence artificielle, le big data ou les environnements de développement. Les entreprises peuvent tester et utiliser des services très avancés sans devoir installer elles-mêmes des infrastructures complexes. Cela accélère l’innovation et la transformation numérique dans de nombreux secteurs professionnels.

Source

Les risques et inconvénients du cloud computing

Même si le cloud computing présente de nombreux avantages, il comporte également plusieurs risques importants. Le principal concerne la sécurité des données. Les informations de l’entreprise sont stockées sur des serveurs distants appartenant à un fournisseur externe. En cas de mauvaise configuration, de faille de sécurité ou de cyberattaque, des données sensibles peuvent être volées ou exposées. Les entreprises doivent donc mettre en place des politiques de sécurité strictes, des sauvegardes et des systèmes de chiffrement pour protéger leurs informations.

Source

La dépendance au fournisseur cloud représente également un risque important. Lorsqu’une entreprise utilise fortement une plateforme cloud, il peut devenir difficile et coûteux de changer de fournisseur par la suite. Certaines infrastructures ou applications deviennent parfois très liées aux technologies spécifiques d’un fournisseur. Ce phénomène est appelé « vendor lock-in ». Une panne importante chez le fournisseur peut aussi rendre certains services indisponibles pendant plusieurs heures.

Source

Le cloud dépend entièrement de la connexion Internet. Si une entreprise rencontre des problèmes réseau ou une coupure Internet, l’accès aux données et aux applications hébergées dans le cloud peut devenir impossible. Cela peut fortement perturber l’activité de certaines entreprises qui utilisent des outils cloud en permanence. Les performances peuvent également varier selon la qualité de la connexion réseau disponible.

Source

La confidentialité des données soulève aussi des questions importantes. Les données hébergées dans le cloud peuvent parfois être stockées dans différents pays, ce qui implique des réglementations juridiques variées concernant la protection des informations personnelles. Les entreprises doivent vérifier que les fournisseurs respectent les normes de sécurité et les réglementations comme le RGPD en Europe.

Source

Enfin, même si le cloud peut réduire certains coûts, les dépenses peuvent rapidement augmenter si les ressources utilisées sont mal gérées. Le stockage massif de données, les services avancés ou les transferts importants de données peuvent générer des coûts élevés sur le long terme. Les entreprises doivent donc surveiller attentivement leur consommation cloud afin d’éviter les dépenses inutiles.

Source

État actuel du cloud computing

Aujourd’hui, le cloud computing est largement utilisé dans le monde professionnel. De nombreuses entreprises migrent progressivement leurs infrastructures vers des solutions cloud afin de gagner en flexibilité, en sécurité et en performance. Les services cloud sont devenus essentiels dans des domaines comme l’hébergement web, le stockage de données, la cybersécurité, le développement d’applications ou encore l’intelligence artificielle.

Source

Les principaux acteurs du marché comme Amazon Web Services, Microsoft et Google investissent massivement dans de nouveaux centres de données et dans des technologies avancées comme l’IA ou le cloud hybride. Aujourd’hui, le cloud est considéré comme une technologie incontournable dans la transformation numérique des entreprises.

Source
